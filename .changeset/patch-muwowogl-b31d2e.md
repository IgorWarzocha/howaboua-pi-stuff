Added Pi Chill, an optional extension that folds routine tool activity into a compact conversation block with user-controlled original details. The block shows the current tool action or reasoning heading, including nested Code and Notebook calls. Reasoning bodies and collapsed thinking labels are hidden from chat without changing stored messages. Routine Shepherdr board notices appear only when expanded. Errors and interruptions keep compact indicators without opening details. Blocking prompts and commentary remain visible.
