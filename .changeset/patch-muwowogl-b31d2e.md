Added Pi Chill, an optional extension that folds routine tool activity into a compact conversation block with user-controlled original details. The block shows the current tool action or reasoning heading, including nested Code and Notebook calls. Routine Shepherdr board notices appear only when expanded. Errors and interruptions keep compact indicators without opening details. Blocking prompts remain visible. Commentary and thinking keep Pi's native presentation.
