Add Grok realtime voice with the current Pi agent doing the work.

- Extension API for typed local voice tools, listed in settings, with a development guide and runnable example; optional xAI web search with visible reported queries.

- Experimental Linux, macOS and Windows local audio with selectable devices and shortcuts, plus trusted-LAN browser control with Pi activity, theme, phone home-screen support and audio warnings.
- Local and browser dictation into an editable draft using xAI speech-to-text, without automatically sending requests.
- Automatic resume after a dropped voice connection, preserving audio ownership and mute state.
- Refuse voice and dictation startup while PCC or GipPity owns active audio in the same Pi session.
- Tabbed settings for next-call voice and model choices, speech speed, language, reasoning, silence follow-up, context and tools.
- Custom personality and instructions appended from global and project Markdown files.
- Spoken goodbye before hangup, with playback completion and caller interruption respected.
- Distinct voice transcript boxes and session-saved call diagnostics.
- Streamed Pi assistant updates, visible working status, plain-text delegation and silence follow-up only while Pi is idle.
- Conversation continuity summaries with a selectable model and reasoning level, saved in the session and refreshed after compaction.

Choose OAuth or API-key access using the matching credential configured in Pi. Unavailable choices are rejected before saving. Voice quota and billing attribution depend on your account.
