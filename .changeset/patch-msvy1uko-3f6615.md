Run the first-class `@howaboua/pi-pet` package as a GipPity Remote miniapp with Clawa browser, voice, and transparent desktop presentation. Attach displays through Pi-owned SSH commands that keep a versioned source build under `~/.pi/agent/pi-pet`, rebuilding only when the loaded package changes and without installing an app or enabling background startup.
