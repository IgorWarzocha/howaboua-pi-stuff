- `daemon.ts` outlives Pi. Controller owns lifecycle. No instance stop on Pi shutdown.
- Disk-only checkpoints. Reapply image/resource/tmpfs and restart services on reopen. No process/RAM resume.
- SDK cancel stops host wait, not guest process. `processes.ts`: detached handles/explicit kill. Agent waits don't hold foreground-exec/file-RPC lock or lifecycle queue. Only setup has hard aggregate deadline and descendant cleanup.
- `services.ts`: editable guest declarations, sticky ports. Reconcile persisted ownership even without live entries. Raw preview links separate.
- Close owned HTTP/WebSocket and SSH before checkpoint or upstream can hang.
- Durable runtime state and disk paths. No silent instance recreation/discard for customisation.
