# @howaboua/pi-skill-harness-and-agent-engineering

Portable Pi skills for diagnosing, designing, auditing, and calibrating agent harnesses.

## Install

```bash
pi install npm:@howaboua/pi-skill-harness-and-agent-engineering
```

Pi discovers these skills after installation:

- `agent-session-diagnostics`
- `agent-tool-design`
- `extension-design`
- `harness-checklist`
- `instruction-calibration`
- `prompt-caching`
