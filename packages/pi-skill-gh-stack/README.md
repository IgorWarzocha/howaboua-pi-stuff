# @howaboua/pi-skill-gh-stack

Pi skill for planning and operating native GitHub stacked pull requests with the official `gh stack` extension.

## Install

```bash
pi install npm:@howaboua/pi-skill-gh-stack
gh extension install github/gh-stack
```

The skill covers dependency-based stack design, noninteractive agent commands, mid-stack changes, remote synchronization, conflict and divergence recovery, externally managed branch linking, and safe partial or whole-stack merging.
