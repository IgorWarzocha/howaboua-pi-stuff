# @howaboua/pi-skill-prompt-cache-awareness

Designs and reviews Pi prompts, tools, provider payloads, transport and compaction without accidentally destroying reusable prompt prefixes.

## Install

```bash
pi install npm:@howaboua/pi-skill-prompt-cache-awareness
```

The skill covers OpenAI's current prompt-caching contract, Codex request construction, Pi's extension hooks, `pi-codex-conversion`, Responses and WebSocket continuation, dynamic tools, reasoning switches and cache measurement.
