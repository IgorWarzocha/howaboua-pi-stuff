- Monitor instructions retain initial scope and the latest message, not a transcript. Full messages stay in native session history. - Session readers walk the active parentId chain backwards from EOF, never load whole transcripts. Unclaimed reports steer active controllers. - Delivery discovers PCC through its developer-custom-message/v1 receipt, not a runtime import. Only no receiver or unavailable may fall back to native delivery; delivery errors must not send again. nextTurn never requests rollover admission.

Refresh metadata in place so renames retain connection/watch owners. Delegate setup to interactive hc machine add with its approvals and OpenSSH ownership; never maintain another catalogue or legacy environment fallback.

Reconnect only on activation, catalogue refresh or explicit action, never timers. core/remote-transport.ts owns lazy helper lifetime, pending calls, subscriptions and reverse context calls. Close focus channels and abort context callbacks before releasing their connection owner.
- Keep agents available in every mode and start monitoring at session startup. /herdr is the sole command entry. Peer lifecycle dispatch uses live command context, never captured context.
- AgentsParameters is a discovery envelope, not the full action schema. Keep additionalProperties explicit so native codemode renders an open input type; action fields belong in help and runtime validation.
- The human panel owns preferences and machine setup/troubleshooting. Agent discovery, attachment, detachment and membership belong to tools. Explicit orchestration changes only guidance and restores from session messages. Refresh UI through events. Keep schemas, guidance, acknowledgements and injected events compact, without repeated state/IDs.

- Idle tasks use native custom kickoffs through every before_agent_start hook. Template/slash inputs remain user kickoffs. Track preparation as running for peer inbox and shared-context delivery. Session readers must recognise it as task input.
