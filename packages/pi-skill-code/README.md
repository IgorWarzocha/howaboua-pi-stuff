# @howaboua/pi-skill-code

Portable Pi skills for reviewing, changing, researching, and delivering maintained code.

## Install

```bash
pi install npm:@howaboua/pi-skill-code
```

Pi discovers these skills after installation:

- `codebase-hygiene`
- `code-review`
- `project-reference-research`
- `repository-delivery`
- `scratchpad`
