# Pi Reactions

Click an emoji below a finished reply, or use `/react` to pick a reaction for the latest reply by keyboard. Click the selected emoji again to remove it.

| Reaction | Meaning                                                  |
| -------- | -------------------------------------------------------- |
| 👍       | Looks good                                               |
| 👎       | Reconsider                                               |
| ⬆️       | Push to the existing remote branch, not merge or release |
| 🔍       | Verify the claim or run the check discussed              |

Reactions don't start or interrupt a turn. Pending reactions go with your next ordinary prompt. Commands and messages queued during a run leave them pending. Delivered reactions remain marked on the reply. Removing a mark cannot unsend an instruction. Reactions don't approve pending tool calls.

Requires Pi 1.7. Use fullscreen mode for mouse interaction. Load the checkout with `pi -e ./packages/pi-reactions/src/index.ts`.
