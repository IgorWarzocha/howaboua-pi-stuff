- Keep one shared serial VM and disposable isolated VMs. JavaScript executes as async global scripts, never function-wrapped cells or replayed history.
- Snapshot only settled, tool-quiescent cells. A stalled cell or outstanding host calls invalidates the VM; later replies must never reach a replacement cell. Keep tools routed through CodeModeDelegateRuntime.
- Preserve the boot-time controller handle token across every restore. Exporting new tokens per checkpoint leaks retained VM references. Rebind only named host callbacks, never replay user code to recover them.
- Keep support roots separate from the immutable prelude. Capture graph IDs before the native image containing their WeakMap. Management clones inherit startup state; actual restores rerun startup.
- Selective mutation runs in a full-image candidate, persisted before adoption. Never rebuild the live heap from data recipes. Project sync follows the session commit; persist the submitted candidate as the observed baseline, not other sessions' unseen values. Unsupported pins must not delete shared data.
- Drain guest jobs fully before each tool reply. Hold user settlements until queued hooks finish; hook-origin replies settle directly. Quiescence checks must use outstanding host calls, not only controller promises waiting on hooks.
- Whole-VM images are version-bound. Bump the storage fingerprint when changing bridge/worker snapshot semantics or the engine; incompatible images fail visibly, never reset implicitly.
- Binding inventory is parsed metadata, not rewritten execution. Register declarations only after native evaluation accepts the script, including rejected async cells with surviving TDZ bindings. Never invoke global accessors for inspection. JSN2 adds inventory outside the unchanged engine image; JSN1 still restores with an explicitly incomplete inventory.
- Use public Pi/QuickJS exports only. Pi's private one-shot VM/prelude is a reference, not an import path. Node worker termination is required for infinite microtask chains; do not enable Bun without proving that boundary.
